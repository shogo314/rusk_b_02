# Rusk β 02

Rusk は競技プログラミング向けの言語です。作者自身にとっての書きやすさと、競技プログラミングで十分な実行速度を重視して開発しています。

このドキュメントは第2段階の `rusk_b_02` を対象とします。完成したプロトタイプ版 [rusk_b_01](https://github.com/shogo314/rusk_b_01) の実装・設計・テストを出発点に開発を続けます。

!!! note "開発状況"
    C++20 を生成するプロトタイプです。基本型の入出力、整数演算、共有・コピー・代入、短絡論理演算、条件分岐、while / for、再帰とオーバーロードが使えます。多次元配列、ソート・二分探索、ASCII 文字列操作にも対応します。一般のジェネリクスや実行速度の最適化は今後の課題です。
